# Galaksi Tulisan Ajaib

Game web interaktif untuk **Asas 3M – Bahasa Melayu, Tahun 1 Pendidikan Khas (Masalah Pembelajaran)**.

## Tiga tahap
- ☁️ Kumpulan Awan — TP1: menyurih huruf bertitik dengan bimbingan
- 🌙 Kumpulan Bulan — TP2: menyalin huruf berdasarkan contoh
- ⭐ Kumpulan Bintang — TP3: menulis huruf awal berdasarkan gambar tanpa contoh

## Cara letak di GitHub Pages
1. Cipta repository baharu, contoh: `galaksi-tulisan-ajaib`
2. Upload fail `index.html` ke root repository.
3. Pergi ke **Settings → Pages**
4. Di **Build and deployment**, pilih **Deploy from a branch**
5. Pilih branch **main** dan folder **/(root)**, kemudian Save.
6. Tunggu GitHub Pages menghasilkan pautan laman.

## Ciri
- Huruf besar A–E dan huruf kecil a–e
- Stylus / jari / mouse
- Pilihan warna
- Kesan bintang semasa menulis
- Audio sebutan huruf menggunakan Web Speech API
- Simpan hasil sebagai PNG
- Responsif untuk tablet, telefon dan komputer

Nota: Butang “Selesai” tidak menilai ketepatan bentuk tulisan secara automatik. Hasil PNG digunakan sebagai bukti untuk dinilai guru dan dimuat naik ke Canva Whiteboard.
